# 最终愿景

**让任何人在任何一台陌生机器上，用一个工具快速获得「带着自己上下文的 AI 开发环境」。**

## AI 开发环境随身

换机器时，缺少的不只是可执行文件，还有个人配置、全局规则、prompts 和认证信息。

目标链路是：**环境检测 → 装齐 Agent 工具链 → 恢复加密个人档案 → 校验可用状态**。

已有的安装、扫描、压缩、加密与恢复能力将作为基础。当前 OpenClaw 归档并不等于完整的通用个人上下文档案。

## 用真实场景衡量进展

阶段价值通过可验收场景判断：在一台干净的 Windows 机器上，从缺少工具链到工具可启动、个人配置可用，需要多久；安装失败时能否继续处理；迁移后能否确认文件完整。

这些是持续验收的方向。当前已实现能力与验证边界见[当前能力与验证](./progress)，下一步工作见[开发路线](./roadmap)。

## 不变的约束

- 携带私钥与凭证的载体必须强制加密落盘。
- 安装失败要有镜像／安装包或手动引导，避免中间状态卡住用户。
- 完全无网、物理隔离的内网不属于目标场景。
- OpenClaw 迁移能力继续复用，新增投入围绕工具链准备、上下文携带与可用性校验。
