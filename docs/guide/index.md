# 认识 Deploystrap

Deploystrap（部署器）的目标是：让你在一台陌生机器上，快速获得**带着自己上下文的 AI 开发环境**。

这里的上下文包括 Agent 配置、全局规则、prompts，以及需要安全携带的凭证。长期方向还包括 AgentOpenConnect（AOC）的安装和设备接入。

## 今天可以用什么

| 需求 | 使用入口 | 当前边界 |
| --- | --- | --- |
| 补齐 Node、Git 和 AI CLI | 桌面端「AI 工具」 | 已有实现，完整实机闭环待验收 |
| 安装配置 OpenClaw / Hermes | 桌面端对应面板 | 已有实现，需在目标环境核验 |
| 备份、恢复 OpenClaw 实例 | CLI 或桌面端 | CLI 支持 official / legacy 双引擎；桌面端独立处理 ZIP |
| 携带任意 Agent 的完整个人上下文 | 产品主线 | 通用档案尚未实现 |
| 安装 AOC、导入接入胶囊 | 后续阶段 | 尚未实现 |

## 选择一条开始路径

- **第一次使用**：阅读[快速开始](./getting-started)，从源码构建并选择 CLI 或桌面端。
- **准备工具链**：阅读[安装 AI 工具链](./toolchain)，按依赖顺序检测与安装。
- **迁移已有实例**：阅读[备份与恢复](./migration)，先生成归档，再恢复到新目录核验。
- **参与项目**：先读[最终愿景](/project/vision)和[开发路线](/project/roadmap)。

## 产品边界

OpenClaw 迁移是可复用子能力，产品主线是上下文随身与 AOC 安装／接入。完全无网、物理隔离的环境不属于目标场景；有内部模型网关的内网属于计划支持的使用环境。

项目只负责 AOC 的安装与接入，不修改 AOC 源码。
